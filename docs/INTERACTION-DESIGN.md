## 二、全局元素

- 顶栏（左→右固定序）：资料目录 → 设置 → 大字 → AI → 版本 → ?（IP 入口唯一断言；? 专供疾病概要 IP-DP-1）。
- 声明条：页面最顶部「交互原型 vX + 全部为模拟/合成示例」。
- 侧栏：236px、选中态品牌浅底 + 左侧 3px 竖条；侧栏**没有**设置项（设置=顶栏弹层三 tab）。
- AI 面板：右侧 35%、splitter 可拖 25–45%、收起是隐藏不是卸载（40 号）。

## 三、路径明细（每条：入口名 → 步骤 → 可观察产物 → 回首页）

- IP-INF-1 登记一次输注：输注记录 → 「＋ 登记输注」 → 表单（日期/剂量/g/时长/地点/输注反应，6 字段） → 保存并关闭 → 卡片出现 → 侧栏「看板」回首页。
- IP-INF-2 连续补录：同上选「保存并继续录入」 → 表单保留可再录 → 连续 ≥2 条 → 取消退出。
- IP-FLR-1 标记复发：复发与症状 → 「＋ 标记复发」 → 表单（开始日期/受累部位/感受描述/医生是否已确认） → 保存 → 区间带起点出现。
- IP-FLR-2 标记缓解：列表卡 → 「标记缓解」 → 表单（缓解开始日期/残留症状） → 泳道出现缓解起点；看板状态卡切「缓解中第 N 天」。
- IP-MET-1 化验登记：指标与化验 → 「＋ 登记化验」 → 表单（指标/数值/单位/日期/机构） → 指标卡成组 + 原件挂链。
- IP-CHT-1 看趋势：一图秀 → rail 选指标（按分类分组 checkbox，≤4 条） → 时间窗 chips（全部/近 3 月/近 6 月/近 12 月） → 图更新、末点标签。
- IP-EXM-1 电生理登记：检查与电生理 → 「＋ 登记检查」 → 表单（日期/项目/机构/关键值原文/报告原件） → 检查卡出现。
- IP-MED-1 方案录入：用药档案 → 「＋ 登记方案」 → 医生原话引用模式（原文/日期/出处医生） → 保存为新版本，版本号可见。
- IP-CST-1 记一笔费用：费用与医保 → 「＋ 记一笔」 → 表单（日期/项目/总费用/医保报销/自付） → 卡片 + 页内汇总（读时算）。
- IP-HOS-1 医院登记：就医信息 → 「＋ 添加医院」 → 表单（名称/科室/联系方式/出处引用） → 逐条卡片可加可改。
- IP-VIS-1 复诊清单：复诊清单 → 「＋ 加一条」 → 问题文本 → 条目 +1；见完标已处理。
- IP-REC-1 资料登记：资料库 → 「＋ 登记资料」 → 表单（名称/类型/日期/文件位置引用） → 条目 +1。
- IP-DP-1 疾病概要：顶栏 ？ 或首页文字按钮 → 四段整页面板（定义/医学资料规范和指南情况/治疗全景/发展趋势） → 返回/✕ 双入口 → Esc 退一层 → 焦点回归。
- IP-AI-1 AI 汇总：任一页「和 AI 讨论」 → 原生面板草稿填入（不发送） → 按回车由用户发送。
- IP-AI-0 首次 AI：顶栏「AI 对话」 → 无会话则经宿主 newSession 创建（取消目录选择留提示、失败留原因） → 面板出现。

## 四、AI 候选通道（IP5/IP10/IP11）

- 每个可写实体（输注/复发/化验/检查/用药/费用/医院/清单/资料）提供 AI 候选通道：候选逐项核对，拒收零副作用；红线实体（医生判定类）标「—」。
- 每页标题行常驻「和 AI 讨论」，携带本页关键信息（无判定词）进输入框，不代发；弹窗内也有「和 AI 讨论这个」。

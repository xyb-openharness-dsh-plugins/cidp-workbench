## 二、待验证假设（访谈提纲就绪）

1. 输注节奏记忆是真痛点：患者依赖日历/家属记忆/病友群提醒（对应 F1 的「距上次输注 N 天」卡）。
2. 复发识别靠身体感受：患者自己标记「复发中/缓解中」两态，医生确认才升级为记录结论（对应 F2 双态+医生原文）。
3. 费用焦虑集中在单次输注总费用与医保分段（对应 F7 只记事实：金额、报销金额、自付金额）。
4. 电生理报告跨机构不可比：患者在意「这次和上次不是一个医院查的」（对应 F5 方法/机构可比组标注）。
5. 激素减量方案靠口头传达，家属代记（对应 F6 只录医生原话模式）。

## 三、照护者线

代记场景：家属帮患者记录输注与费用——录入界面必须支持连续多条（三态按钮：保存并继续录入/保存并关闭/取消），字段 ≤6，数字键盘。

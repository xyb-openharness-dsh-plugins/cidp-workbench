# DEV-REQUIREMENTS · cidp-workbench（小髓宝 MyelinPal）

版本：v0.1.0-dev · 状态：草案（无人值守默认值，见 DEV-PLAN §五，晨审追认）

## 一、问题与用户

CIDP（慢性炎性脱髓鞘性多发性神经根神经病）患者需要长期管理三件事：**周期性治疗（IVIG/SCIG 输注）的记录与节奏**、**复发—缓解的经过**、**长期用药的安全监测与费用负担**。公开中文体系信息少，患者靠碎片帖子做决策；本工作台只做「本机资料的整理与回顾」，不做诊断、不给处置建议、不做病情判定。

目标用户：CIDP 患者本人；家属/照护者（协助记录输注与费用）；患者组织志愿者。0 患者访谈，全部需求来自任务口径与病种结构推理，逐条挂待验证标记。

## 三、硬约束（继承夜纲数据层/前端/工程三条）

- 数据层：ORDER BY rowid、显式 null、in_use、分节 *_title、分类不进趋势、演示唯一源；无判读列（diagnosis/risk_level/activity_score 类派生判定不入库）。
- 前端：页脚贴底、[hidden]、字号 12.5–15、面板 25–45% 可拖可收、无判读列、私密三出口代码级过滤。
- 工程：改包必升版；public 与原型 ui-parity；并行写同仓以 check 链为准合流并立即提交。
- AI：输出永远是「候选/预览」；草稿只填不发；agent-draft 协议携带病情上下文（只含事实，不含判定词）。

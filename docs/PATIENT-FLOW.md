# PATIENT-FLOW · CIDP 患者旅程与工作台落点

版本：v0.1 · 非肿瘤表达红线：全程用「复发—缓解 / 受累神经 / 随访节律」表达，禁用分期/线序/疗效排序。

## 旅程五段

| 段 | 患者处境 | 工作台落点 | 缺口如实声明 |
| --- | --- | --- | --- |
| 1 疑似与确诊 | 手脚无力麻木反复几个月，神经内科查电生理、腰穿、排除其它病因 | 确诊档案：只记医生原文与日期；电生理首查登记 | 确诊过程不做自查判定工具（K5） |
| 2 一线治疗启动 | IVIG 冲击数天，之后每 4–8 周维持；或激素起始 | F1 输注按次登记（日期/剂量/时长/地点/反应）+ F6 医生原话方案 | 输注间隔只报事实，不评估「该不该输」（阈值【待核】） |
| 3 维持与随访 | 每次输注间记录状态；定期化验监测安全 | F3 指标卡（血象/免疫球蛋白/生化安全监测/体征）+ F4 一图秀 | 什么算「正常波动」由医生判读，界面不写 |
| 4 复发 | 症状回来或加重，可能提前输注、换二线 | F2 复发—缓解区间带 + 近 90 天发作次数（读时算） | 复发判定 = 医生确认；患者标记只是「待确认」态 |
| 5 长期管理 | 费用负担、医保报销、多院就医、激素副作用监测 | F7 费用 + F8 就医信息 + F10 资料库 + F9 复诊清单 | 无 |

## 事件泳道（照 AML #mind 泳道结构，语义重写）

时间轴上四类事件：**输注 / 复发起止 / 检查（电生理、化验、复诊）/ 用药变更**。单条泳道按时间从上到下；复发—缓解用区间带（对应 1.3 非肿瘤替换表「症状色块日历 band → 发作—缓解区间带」）。

## 状态卡口径（首页 hero，对齐 v0.4 大状态卡）

- 主状态：**缓解中第 N 天** / **复发中第 N 天**（由最近一次复发/缓解标记派生，读时算）
- 副行 1：距上次输注 N 天（最近一次输注记录）
- 副行 2：医生最近一次原文（如「下次输注按第 5 周安排」——只引用，不排程）
- 行动带：登记输注 / 标记复发 / 记一笔症状 / 带问题清单复诊

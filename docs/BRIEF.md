# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：CIDP 患者及家属照护者；正在接受 IVIG/皮下免疫球蛋白/激素/血浆置换治疗的慢性病程患者；复发—缓解与进展型患者；患者组织志愿者协作使用

场景：免疫球蛋白输注按次登记（日期/剂量/输注时长/地点，距上次输注天数读时算）；复发—缓解区间带与发作记录（症状部位/程度，只记事实不判定）；肌力与感觉变化自记（医生原文引用模式）；神经电生理（神经传导/肌电图）复查结果登记（标注方法与机构可比组）；用药档案（激素减量方案只录医生原话）；费用与医保报销记录（每次输注花费）；复诊问题清单与行动提示（医生确认原话）

核心流程：
1. 首次进入建档：确诊信息（只记医生原文与日期）、当前治疗方案概览（医生安排）
2. 日常记录：IVIG 输注登记、复发—缓解标记、症状与肌力变化笔记、费用记录
3. 复诊回顾：输注周期与复发统计概览（读时算）、化验与电生理趋势、带问题清单见医生

完成结果：得到来源可追溯、可核对的个人 CIDP 病程档案：输注周期与间隔一览、复发—缓解时间线、症状与治疗记录版本链、电生理与化验趋势、费用负担概览、复诊问题清单；全部仅回顾不解读，解读归医生

初始布局选择：business-first
